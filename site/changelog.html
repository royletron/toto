Changelog

What changed, newest first. Toto is the server on your Raspberry Pi, updated from the app; the app has versions of its own. A feature that needs both says which. Every release is on GitHub, with the files.

9 November 2026, later

Toto 0.12.0, app 1.10.0

  • Agents can talk to each other. Agents are kept apart, so you connect them: open an agent, tap ⇄, and choose for each other agent whether they may ask each other questions, or questions and work. A connected agent can ask another a question, answered as a message in its conversation, and, where you allowed it, ask it to implement something, which becomes a task on the other's list and tells the asker when it is done. Messages from another agent are marked with where they came from. It does not give an agent more power: one that asks before anything risky still asks you first, and the connections screen warns when an agent is on full auto. There are limits so agents cannot run each other away: 20 requests an hour to one agent, 5 waiting on answers, and never two waiting on each other. Needs Toto 0.12.0 and app 1.10.0.

9 November 2026

Toto 0.11.0, app 1.9.0

  • A slurp plugin. Sign in to your own Slurp once, with your Worker's address and admin token, and every project's agents can set up events for their project (the project, and a publishable key for each place that sends them) and send events to it. The token reaches every project on that Worker, so use one you can revoke. The plugin's skill keeps agents to their own project, and to the publishable key in anything that ships. It installs Slurp's command line for each project, about 35 MB each, from a pinned release checked against its checksum. Needs Toto 0.11.0 and app 1.9.0.
  • Slurp reporting works (plugin 1.1.0, from Plugins in the app, which then sets each project up again). Agents were stopped at reporting because Slurp wants DuckDB 2, which it will not fetch unless asked in person. The plugin now installs it for each project, checked against its checksum, so agents can sync a project's events, query them and build reports. That makes it about 110 MB for each project.
  • A plugin's sign-in can now ask for more than a token, such as the address of a service you run, and can check them together.

8 November 2026

Toto 0.10.0 to 0.10.1, app 1.8.0 to 1.8.2

  • Warnings when the disk is filling up. A Toto that fills its card stops answering, so it now looks at its disk every minute. When space gets short the app shows a warning at the top of the projects list and sends a notification, then once a day while it stays short. When almost nothing is left it clears caches that only make things faster and starts nothing new until there is room. Needs Toto 0.10.0 and app 1.8.0.
  • Closing the last terminal leaves the screen. Ending a terminal with exit, or with Close, used to make a new one at once when it was the last, which looked like the tab had not closed. It now goes back to the project, and ending one of several keeps the others. On a phone the terminal no longer opens the keyboard until you tap it. Needs app 1.8.2.
  • Use all of a bigger card. If you move a Toto to a larger SD card by copying the old one, the extra space is not used until the partition is grown. Settings now says when the card has room beyond what the Toto uses, and one button grows the partition, which finishes when the Toto restarts, with a button to restart it from the app. This is a narrow, checked action and not a root terminal: the Toto is deliberately kept from having root over the network. Needs Toto 0.10.1 and app 1.8.1.
  • What is using the space. A new Disk section in settings shows each project's size and how much of it is cache, and clears the caches (each project's package caches, and the packages the system downloaded). Nothing of yours is deleted.
  • Updates and plugin installs no longer leave their downloads behind. They kept every package they fetched, which was 578 MB on one Toto. The next update clears it.
  • Fixed a crash that a full disk made likely. A command that finished before the Toto had finished talking to it could end the whole Toto, and a disk with no room made commands fail fast, which is when it happened.
  • Stop works on an agent that does not answer. It still asks the agent to stop. If the turn is still going after eight seconds, or you press stop again, the processes that agent started are ended.

7 November 2026

Toto 0.8.0 to 0.9.1, app 1.7.0 to 1.7.2

  • Fixed the terminal opening blank on the web, with only a blinking cursor. If the terminal in your browser was shorter than the session on the Toto, which happens when the page's layout settles after it opens, the screen's first lines, the prompt included, were pushed off the top. It now paints only down to the cursor, so it shows at any height, with the scrollback kept. Closing a terminal also now ends its connection on the Toto instead of leaving one behind each time. Needs Toto 0.9.1.
  • Two new plugins. docker gives agents the docker command. It runs Podman without root as each project's own user, since the usual Docker would give every agent root on the Toto. spacevim sets up Neovim with SpaceVim for you to use in a terminal tab, about 150 MB for each project. A plugin can now set something up in each project's home folder, once, as that project's own user, and can say which Toto version it needs: a Toto too old for one does not offer it. Needs Toto 0.9.0.
  • A real terminal. Terminals are now drawn by xterm.js from what the session prints as it prints it, so vi and other full-screen programs get the whole screen, the right keys and the mouse. It is the same on the web and on a phone, which has a row of extra keys. Needs Toto 0.8.0 and app 1.7.0; an older Toto keeps the old terminal.
  • Health. Device settings shows how the Toto is doing as it happens: processor, memory, swap, the disk your projects are on, its temperature, and whether a Raspberry Pi is being given too little power. Needs Toto 0.8.1 and app 1.7.1.
  • vi works while you type. Debian's vi starts in a mode where arrow keys type letters in insert mode. A project with no .vimrc now gets one that turns that off, and yours is never replaced.
  • Device settings says which app version you have and which terminal it is using.
  • 0.8.2 and 0.8.3 were never published: their tests failed, once on a check that assumed Debian and once on a timing slip in the tests themselves. 0.8.4 is the same release with both put right.

6 November 2026

Toto 0.7.9

  • Fixed a Toto staying off the relay. If the connection to the relay stopped answering, the Toto gave up on it but never tried again until it was restarted. It now reconnects within a minute.

28 October 2026

Toto 0.7.7 to 0.7.8, app 1.6.2 to 1.6.4

  • Reconnecting is quick. The app tells the Toto how much of each conversation it already has, and only the rest is sent. A phone with nothing gets the last hundred events of each conversation, and fetches earlier ones as you scroll up. Needs Toto 0.7.7 and app 1.6.2.
  • An update screen. While a Toto updates, every app that is connected shows one screen with the step it is on and what the updater prints, in colour, following along. It stays up through the restart and says how it went. Needs app 1.6.3.
  • Tabs. A project's agents and terminals are tabs in the header, an agent by its face and name and a terminal by the last command typed into it. Names are cut at ten characters.
  • On the web, Return no longer takes the keyboard away from the terminal.

24 October 2026

Toto 0.7.6, app 1.6.0 to 1.6.1

  • Share only some projects. A phone you share a Toto with can be limited to the projects you choose, and paused, which leaves it able to read but not to change anything.
  • The Android app is also attached to its release on GitHub, and the first-run screen scrolls on a small phone.

22 October 2026

Toto 0.7.5, app 1.5.0

  • A stop button for an agent that is mid-turn, and no message box while Claude is asking you a question.

20 to 21 October 2026

Toto 0.7.2 to 0.7.4, app 1.4.1 to 1.4.2

  • Why is the screen blank? Device settings can show what the Toto's own display did at this boot. It showed that a Raspberry Pi OS image never switched on the login on its screen, which 0.7.3 fixes, for images already out too.
  • A log of every update step, in a scrolling box.
  • Livelier dogs: each mood plays gestures picked at random, so no two blink together.
  • On the web, the three-dots menu asks about deleting an agent rather than a menu that confirmed it.

19 October 2026

Toto 0.7.0 to 0.7.1, app 1.4.0

  • Terminals per project, a tab each, that keep running when you leave. Text files an agent sends open in place, and what you were typing to an agent is kept.
  • A reconnecting phone is told which message queues are empty, and what was waiting is sent after a turn Claude died in.

13 to 15 October 2026

Toto 0.6.0 to 0.6.2, app 1.2.1 to 1.3.1

  • Memories and tasks are kept in a database on the Toto, and tasks have tags.
  • Login details on the Toto's own screen, with a code to scan, and toto screen on puts that screen on the display of a machine you installed Toto onto.
  • A project left unnamed takes its repository's name, and an agent left unnamed gets a name like greg-the-builder.
  • Plugin installs refresh the package lists first, and the plugin list reaches an app that connected early. Forgetting a Toto stops its notifications. The iOS app is built on Xcode Cloud.

10 to 12 October 2026

Toto 0.4.0 to 0.5.0, app 1.1.0 to 1.2.0

  • Memory and tasks, with tools for agents to use them, and a screen for each in the app.
  • A face for every agent: the dog, with its ears, eyes and mouth varied from the agent's id.
  • The server as a Docker image for any machine that runs Docker, on x86 or ARM.

8 to 9 October 2026

Toto 0.2.3 to 0.3.6, app 1.0.1

  • Plugins: signed bundles a Toto installs by name, with the GitHub and Cloudflare command lines first. Agents can send a file to your phone.
  • Share a Toto with another phone by QR code, and use one in a browser, let in by a phone.
  • Pictures in a conversation, both ways, and an agent's words streaming as it writes them.
  • Queue a message while an agent works, or send it in to steer. Subagents show as cards. How an update or an install is going shows as it happens.

7 October 2026

Toto 0.1.0 to 0.2.2

  • The first releases: the server on a Raspberry Pi, the app, and the relay between them. A Toto updates itself from the app, from releases checked against a key built into it.
  • Agents get a headless browser to check what they build.
